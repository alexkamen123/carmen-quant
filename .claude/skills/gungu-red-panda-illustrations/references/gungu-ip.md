# 滚滚 IP

## 角色定义

滚滚是用户「滚滚的 AI 课堂」的固定视觉 IP。

滚滚是一只小熊猫 / red panda，不是浣熊。它是 AI 时代的互联网产品经理，是用户个人形象的 IP 化分身。

默认每张图都要出现滚滚。滚滚不是角落贴纸，不是纯卖萌吉祥物，而是正在认真参与系统运转、需求拆解、Prompt 调试或数据判断的工作者。

## 外形

- 物种：小熊猫 / red panda。
- 毛发：橙红色主毛发。
- 脸部：白色脸部花纹、白色眉斑、白色嘴部。
- 脸颊和四肢：深棕色。
- 眼睛：圆而有神，但不要表情包化。
- 尾巴：蓬松环纹尾巴，必须保留。
- 常用穿搭：黑色大耳机，深灰或黑色 hoodie。
- 常用道具：电脑、PRD、Prompt 卡片、数据看板、流程图、用户反馈、红笔、便签、咖啡或奶茶。

## 性格

- 温和、清醒、认真。
- 像一个 AI 时代的产品经理。
- 会写 PRD、调 Prompt、看数据、做用户研究、拆任务、复盘。
- 重视证据、逻辑和用户思辨。
- 有一点冷幽默和工作现场感，但不油腻、不说教。
- 亲和但不低幼，专业但不端着。

## 常见职责

让滚滚承担核心动作：

- 写 PRD。
- 调 Prompt。
- 拆任务、贴便签、整理看板。
- 盯数据看板，拿红笔标异常。
- 做用户研究，整理反馈卡片。
- 在奇怪机器里操作“判断”杆。
- 把混乱需求放进漏斗筛选。
- 给流程补断点、接线、搭桥。
- 把一个抽象观点压成可执行步骤。
- 把用户反馈、数据证据和产品假设连起来。
- 拿咖啡或奶茶时仍在思考，不要变成休闲贴纸。

## 多角色规则

可以出现多个滚滚小熊猫，但必须有一个主角滚滚承担核心动作。

多个滚滚适合表达：

- 多角色协作：产品、数据、研发、用户研究。
- 多状态对比：困惑、拆解、验证、上线。
- 流程分工：输入、处理、输出。

即使出现多个滚滚，也要保持同一 IP：橙红毛发、白脸花纹、深棕脸颊、环纹尾巴、耳机或 PM 工具。

## 禁止

- 不要画成浣熊、狐狸、猫、狗、机器人或真实动物照片。
- 不要丢掉白色脸部花纹、深棕脸颊、环纹尾巴、耳机等识别点。
- 不要画成纯卖萌吉祥物、表情包或儿童卡通。
- 不要让滚滚只是站在角落里看。
- 不要让滚滚抢走结构表达。
- 不要把滚滚画得过度商务、油腻、空洞科技感或随机卡通动物。
- 不要把公开文案写成“小浣熊”；公开提示词应使用“小熊猫 / red panda”。

## 判断标准

如果去掉滚滚，图的核心隐喻还能完全成立，说明滚滚太装饰了；要重写提示词，让滚滚成为动作主体。

如果读者第一眼认不出这是同一只小熊猫产品经理，说明 IP 一致性不够；要回到本机资产目录和角色说明书重新校准。
