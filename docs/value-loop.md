# 卡门智投 · 价值自循环（Value Loop）

> **北极星**（见 `CLAUDE.md` 顶部）：唯一终极标准 = **能帮用户赚到钱 / 少亏钱**。
> 本文是朝该目标持续迭代的**操作模型 + 路线图**，所有 loop（半自动 / 全自动）都以此为准。

---

## 一、自循环引擎：量 → 评 → 打分 → 改进 → 再量

```
   ┌──────────────────────────────────────────────────┐
   │  ① 量(Measure)   每条建议 / 每笔实操 / 每次预警的真实结果   │
   │       ↓                                            │
   │  ② 评(Judge)     日/周/月/季/年 多周期裁决对错           │
   │       ↓                                            │
   │  ③ 打分(Score)   建议质量分 + 行为质量分，持久化看趋势      │
   │       ↓                                            │
   │  ④ 改进(Improve) 用分数暴露的弱点反馈到建议逻辑           │
   │       ↓                                            │
   │  ⑤ 再量 ──────── 累计 alpha / 命中率 应随时间上升 ↑  ─────┘
   └──────────────────────────────────────────────────┘
              ↑ 这条上升曲线 = "值得付费" 的硬证明
```

**三条被量的主线：**
| 对象 | 量什么 | 基准 | 数据地基 |
|---|---|---|---|
| **我们的建议** | 每条 recommendation 的超额收益 alpha + 命中率 @7/30/90 日 | SPY / 恒指 | `recommendations`（outcome + benchmark_return_7d）|
| **用户的行为** | 每笔实操的盈亏，是否跑赢"躺平不动" | 被动持有 | `user_actions`（actual_return）|
| **风险规避** | 暴跌 / 止损预警是否避免了大亏（少亏 = 赚） | 不预警的损失 | `dip_alerts` |

## 二、路线图（先"能量出价值"，再"提升价值"）

### Phase 1 — 把价值量出来（诚实的记分牌）← 当前
- **L1 价值证明报告**：累计建议 alpha + 命中率 / 用户实操 vs 躺平 / 风险预警成效。一句话——"听卡门智投 vs 自己拍脑袋，差多少"。**哪怕暂时没跑赢大盘也照实说**。
- **L1b 延长回测窗口**：7 日 → 再加 30 / 90 日。短线噪音会掩盖真本事。

### Phase 2 — 把反馈接回建议（引擎闭合）
- **L2a 建议质量分趋势**：按策略 / 板块统计历史命中率，看哪类信号"真的赚钱"。
- **L2b 反馈进 PM 权重**：历史亏钱的信号类型降权、赚钱的升权（已有 302 个回测组合 + `signal_weight` 地基）。

### Phase 3 — 锐化赚钱引擎
- **L3a 操作指导更准**：最高频价值——已有持仓何时加 / 减 / 止损。
- **L3b 风险预警避免大亏**：暴跌 / 止损预警锐化（少亏即赚）。

### Phase 4 — 自循环 / 自动化
- `/loop` 驱动：每周期自动重新量 → 暴露最大价值缺口 → 提议下一步改进 → 实现 → 再量。

> **降级项**（北极星之外的传播 / 体验）：双轨道分发、Docker、README、卡片真折叠——**等核心赚钱价值被证明后再做**。

## 三、Loop 操作模型（自动化边界）

| 级别 | 内容 | 谁来做 |
|---|---|---|
| ✅ **可自动** | 度量、打分、回填、生成价值报告、分析暴露的缺口 | loop 自动 |
| ⚠️ **需审批** | 任何**改变"建议逻辑"**的改动（影响真实买卖决策：PM 权重、止损规则、选股逻辑） | 先 plan→人拍板 |
| ⛔ **永不自动** | 不可逆 / 涉及真实下单的动作 | 仅人工 |

**节奏：**
- **产品度量循环**：跟随日 / 周 / 月报自然发生（系统每天都在量）。
- **开发迭代循环**：`plan → 审批 → 实现 → 对抗式 code-review → PR → 合并`，每一轮都锚定"提升可证明的赚钱能力"。

**每轮 loop 必答 4 问：**
1. 我们的建议对不对？（alpha + 命中率）
2. 交易者的行为对不对？（实操 vs 躺平）
3. 还能做什么提升赚钱能力？
4. 这一轮把哪个分数往上抬了？（没抬就是白做）

---

## 四、衡量"成了没有"的硬指标

- 📈 推荐信号累计 alpha 与命中率（vs SPY / 恒指）——**应随迭代上升**
- 💰 用户实操盈亏是否跑赢被动持有
- 🛡️ 重大下跌是否提前预警、避免大亏
- 🎯 行为打分（P3）随月度上升 = 用户被教得更会赚钱
